# zherong0603-web

AI-assisted workflow assessments and focused Node.js / TypeScript fixes.

## Work Inquiries

Available scopes include:

- A small, reproducible bug in an existing Node.js or TypeScript project, with a focused patch and relevant verification.
- An assessment of one recurring business workflow: inputs, handoffs, exceptions, one proposed change, and a measurement plan.

Reference rate: **US$30/hour**. A discovery engagement can be scoped to a five-hour cap. The actual scope, acceptance criteria, price and delivery date are agreed before an engagement starts.

[Open a work inquiry](https://github.com/zherong0603-web/zherong0603-web/issues/new?template=work-inquiry.md)

**GitHub issues are public.** Share only public or redacted reproduction steps and a brief description of the desired result. Private code, customer records, credentials and payment details need a separately agreed private channel.
